Frequently Asked Questions

How do I use the extension?

+

1. Navigate to a Threads user's media page: threads.net/@username/media
2. Click the extension icon
3. Click "Download Media" or "Prepare Queue"
4. For existing downloads, choose to resume or download all

What filename format is used?

+

Files are saved as: {username}_{YYYY-MM-DD_HH-M-S}.{ext}
Example: santhosh_shiva11_2026-02-21_16-41-32.jpg
If multiple posts have the same timestamp, a suffix is added: _1, _2, etc.

Can I export post metadata?

+

Yes! Enable metadata export in settings to collect: username, datetime, post permalink, media URLs, content, like count, and reply count. Choose JSON or CSV format.

Does it work on private posts?

+

The extension can only download media from posts visible to you on Threads. It cannot access private or restricted content.
